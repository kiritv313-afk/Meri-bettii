# i love you art 💌

Drop any pic and it gets rebuilt out of tiny "I love you" letters in 21 languages (Spanish and Gujarati included).

- Animated reveal: type in, random pop, burst from center, rain down
- Original colors or black & white, dark or white background
- Custom text mode if you wanna use your own words
- Runs fully in your browser, no upload to any server

Just open `index.html`, or use the GitHub Pages link.
